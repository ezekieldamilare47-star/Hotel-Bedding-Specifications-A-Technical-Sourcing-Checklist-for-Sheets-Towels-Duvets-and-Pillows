## Why a Specification-First Approach Matters

Hotel linen is exposed to:

- High-temperature washing, often daily
- Chlorine and heavy detergents
- Tumble drying and ironing
- Constant handling by housekeeping teams

Specifications determine whether linen survives those conditions while still meeting guest expectations.

## Pre-Order Validation Steps

1. Request catalogues covering every category in scope.
2. Order samples of each final specification.
3. Wash-test samples at the hotel's actual laundry temperature and chemistry.
4. Measure shrinkage, colour retention, seam integrity and towel weight after testing.
5. Record approved specifications as the reference for every future reorder.

Treat the approved specification as version-controlled: any change to thread count, GSM, fill or size should be recorded and re-sampled before it reaches production.
